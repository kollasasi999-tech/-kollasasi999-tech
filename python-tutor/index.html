1 · Variables & types ▸

Python figures out the type for you — no need to declare it.

name = "Ada"          # str
age = 36              # int
height = 1.70         # float
is_coder = True       # bool

print(f"{name} is {age} years old")
2 · Lists vs. tuples ▸

Lists can change; tuples can’t. Use a tuple when the data is fixed.

fruits = ["apple", "banana"]   # list — mutable
fruits.append("cherry")        # ok

point = (3, 4)                 # tuple — immutable
# point[0] = 9                 # TypeError!
3 · Loops ▸

Use for to repeat over items, range() for counts.

for fruit in ["apple", "banana"]:
    print(fruit)

for i in range(3):     # 0, 1, 2
    print(i)
4 · Functions ▸

Bundle reusable logic with def. Return a value with return.

def greet(name, excited=False):
    msg = f"Hello, {name}"
    return msg + "!" if excited else msg

print(greet("Sam", excited=True))   # Hello, Sam!
5 · Dictionaries ▸

Key → value lookups. Fast and everywhere in Python.

user = {"name": "Ada", "age": 36}
print(user["name"])          # Ada
user["email"] = "ada@x.io"   # add a key

for key, value in user.items():
    print(key, "=", value)
